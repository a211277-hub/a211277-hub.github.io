Milestones of Mobile Programming (TK2323)

▶

Lab 1: UI & Layouts

Explored declarative UI using Jetpack Compose. Practiced structuring layouts with Rows, Columns, and Modifier options to achieve clean screen grids.

💭 "Visualizing instant design changes using the Compose Live Preview was highly satisfying!"
▶

Lab 2: State Logic

Investigated state-driven updates utilizing remember and mutableStateOf to configure clickable items and dynamic text interactions.

💭 "Learning state-hosting principles gave me a clear perspective on unidirectional data flow."
▶

Lab 3: Material Design 3

Implemented Material Design 3 guidelines, crafting beautiful themes with custom pastel color palettes and accessible typography styling.

💭 "Choosing a pink-accented design makes the wellness experience feel highly welcoming!"
▶

Lab 4: App Navigation

Configured NavHost, back stack handling, and passed arguments safely to design professional transitions across screens.

💭 "Mastering clean screen routes changed my design vision from individual screens to holistic architectures."
▶

Lab 5: Room DB Persistence

Integrated Room SQLite libraries to build DAO models, facilitating offline access to logs and permanent state records.

💭 "Saving persistent data offline is a critical step for modern habit-forming tools like PolaFit."
